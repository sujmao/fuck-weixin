接入你自己的网站

单文件、零依赖，100% 复现原站效果：

  1. 自动拦截：<script src="fuck-weixin.js" data-auto></script>
  2. 手动调用：FuckWeixin.init() 或 FuckWeixin.detect()
  3. 自定义文案：FuckWeixin.init({ title:"请在浏览器打开", tip:"微信内受限" })
在真实微信里测试：把部署后的 GitHub Pages 链接发给「文件传输助手」，在微信里点开即看到 100% 复现效果； 或用微信「扫一扫」识别二维码访问。桌面浏览器默认不拦截，点顶部按钮模拟预览，弹窗内「重置预览」可恢复页面。
